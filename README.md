# RAG Concepts

This repository contains three Jupyter notebooks that explain the core concepts of Retrieval-Augmented Generation (RAG) through hands-on examples.

# Files

**Keyword_vs_Semanticsearch.ipynb**
Demonstrates the difference between traditional keyword search and semantic (embedding-based) search.

**Copy_of_Text_Embedding_Modals.ipynb**
Explores text embedding models and how semantic similarity enables effective document retrieval in RAG systems.

**Copy_of_Multi_Modal_Embedding.ipynb**
Shows multimodal embeddings (text–image) using CLIP for cross-modal retrieval.

# What This Covers

* Why keyword search is insufficient for modern AI systems

* How embeddings enable semantic retrieval

* How multimodal retrieval extends RAG beyond text
